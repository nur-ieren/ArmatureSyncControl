# ArmatureSyncControl

[English](README.md)

Unity Editor上でアーマチュアの階層構造や、関連するアバター設定を同期するためのツールです。

## コンセプト

ArmatureSyncControlは、アバターの更新作業を簡略化するために開発されました。

アバタープロジェクト間で衣装やアクセサリーなどの要素を移植する際、アーマチュアの階層構造やコンポーネント設定の違いによって、繰り返し手動で調整する必要が生じることがあります。

このツールは、参照元と適用先のアーマチュア間で対応するボーンを照合し、設定を同期することで、こうした作業の負担を軽減します。

## 概要

- **Unityバージョン：** 2022.3.22f1
- **メニュー：** `nur_ieren > Armature Sync Tool`

## 機能

- **Transformの同期** — 対応する参照元ボーンから、ローカル座標の位置・回転・スケールをコピーします。
- **Active State・Tagの同期** — GameObjectの有効状態とTagをコピーします。
- **PhysBoneの同期** — 対応するPhysBoneおよびPhysBoneColliderコンポーネントの追加・削除・設定のコピーを行います。
- **その他のコンポーネントの同期** — 不足しているコンポーネントの種類を追加し、MA Scale Adjusterなどのコンポーネントを含むシリアライズされた設定をコピーします。
- **参照先の再マッピング** — コンポーネントが参照しているオブジェクトについて、参照元の階層内のオブジェクトから適用先の対応するオブジェクトへの再割り当てを試みます。
- **BlendShapeの同期** — 対応する階層上の兄弟オブジェクトにあるSkinnedMeshRenderer間で、名前を基準にBlendShapeのウェイトをコピーします。
- **Modular Avatarコンポーネントの任意削除** — BlendShapeの同期前に、適用先アバターからModular Avatar Blendshape SyncおよびShape Changerコンポーネントを削除できます。
- **未対応ボーンの一覧表示** — 適用先の階層にのみ存在するボーンを一覧表示し、Hierarchy上で選択できます。
- **Prefab・ボーン参照の保護** — ネストされたPrefabの内容を同期対象から除外し、SkinnedMeshRendererから参照されている一部の未対応ボーンを保護します。
- **Undoへの対応** — 対応している変更は、Undoで取り消せるようにまとめられます。

## 使い方

1. Unity 2022.3.22f1でアバタープロジェクトを開きます。
2. `nur_ieren > Armature Sync Tool` を開きます。
3. 参照元アーマチュアと適用先アーマチュアをそれぞれ指定します。
4. 同期したい設定を選択します。
5. `実行（同期 + 適応側にしかないボーンをリスト化）` をクリックして、同期を実行し、未対応ボーンの一覧を生成します。
6. 必要に応じて未対応ボーンの一覧を確認し、Hierarchy上で選択します。

`リストだけ更新` をクリックすると、同期を実行せずに未対応ボーンの一覧のみを更新することもできます。

### 注意事項

- 参照元アーマチュアが設定のコピー元となり、適用先アーマチュアに変更が反映されます。
- ボーンは主に名前を基準に照合されます。同名のボーンが複数存在する場合は、階層パスを使用した照合を試みます。
- 最上位のアーマチュア同士は、名前に関係なく対応付けられます。
- 参照元に存在しない場合、または参照元に同じ種類のコンポーネントが適用先より少ない場合、適用先のPhysBone関連コンポーネントが削除されることがあります。
- その他の種類のコンポーネントは自動的に削除されません。
- 未対応ボーンが自動的に削除されることはありません。このツールは一覧表示のみを行います。
- 特にModular Avatar関連のコンポーネントを扱う場合は、実行前に同期オプションを確認してください。
