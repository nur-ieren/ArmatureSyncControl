## Name
指定した２つのArmatureルートをシンクさせることから、  
"ArmatureSyncControl"  
としました。

## Concept
Project更新の際に元のProjectからの衣装と新規ProjectでのArmatureルートを  
一致させるために作られました。  
おまけ機能もたくさんあります。  

## Overview
Unity2022.3.22f1に導入してご利用下さい。
バージョン管理は追々行います。  

## Features
・異なるArmatureボーンを2つ指定して、そのTransformの値を揃える。
そして、同じルートボーン名を参照して
・Physboneコンポーネントの値を揃える。
